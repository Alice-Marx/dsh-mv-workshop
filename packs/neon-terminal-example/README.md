# Neon Terminal (example) — dsh-mv

Example pack from the dsh-mv template: boot log, chat window, spectrum ring, heartbeat, EXECUTE glitch and a sinking-whale ending. Silent placeholder timeline (120 s, 120 BPM); use it to learn the format.

## How to play / 如何播放

This pack contains **no audio and no lyric text**. Install it from 创意工坊 in the MV 放映室 panel, then choose
your own copy of the song and your own lyrics file (lines are matched to the pack's timings by hash).

本包**不含音频和歌词文本**。在 MV 放映室的「创意工坊」安装后，选择你自己的歌曲文件和歌词文件（按哈希匹配包里的时间轴）即可播放。
